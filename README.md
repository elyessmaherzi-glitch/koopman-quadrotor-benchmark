# Controller Benchmark (Koopman MPC, LQR, PID+DOB)

This repository contains the source code for the experimental protocol comparing 6 control architectures on a non-linear system:
- PID + DOB
- Gray-box MPC + DOB
- Koopman MPC + DOB
- Koopman-stable MPC + DOB
- Koopman-stable + LQR + DOB
- Koopman (raw) + LQR + DOB
